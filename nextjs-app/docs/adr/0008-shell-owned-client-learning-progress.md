# 셸이 브라우저 기반 학습 기록을 소유하고 현재 원본으로 화면을 계산한다

학습 기록은 로그인이나 서버 저장이 필요한 사용자 계정 데이터가 아니라, 한 브라우저에서 학습자가 문서와 데모에 직접 남기는 개인 표시다. 따라서 셸이 `docs-manifest`와 `demos.yaml`에서 현재 기록 대상을 계산하고, 문서 경로와 데모 URL을 키로 하는 완료 기록을 `study_learning_progress` localStorage에 저장한다. 데모 앱에는 기록 로직을 넣지 않으며, 데모 상태는 `done`인 항목만 대상에 포함한다.

## Considered Options

- **문서와 각 데모 앱이 상태를 나눠 소유**: 데모마다 같은 저장·복원·예외 처리를 반복해야 하고 zone 이동 때 학습 기록 계약이 깨질 수 있다.
- **서버 데이터베이스 또는 로그인 계정에 저장**: 여러 기기 동기화는 가능하지만 개인 학습 표시 하나를 위해 인증·서버 운영·개인정보 경계를 추가한다.
- **셸이 현재 원본과 브라우저 기록을 조합**: 셸의 공통 UI에서 문서와 데모를 같은 방식으로 기록하고, 새 항목·공개 상태 변경을 현재 원본에 따라 자연스럽게 반영할 수 있다.

## Consequences

- 저장되는 것은 사용자가 직접 완료 표시한 항목뿐이며, 방문 이력·다음 학습·자동 진도·전체 수치는 저장하거나 제공하지 않는다.
- 현재 원본에 없는 기록은 저장소에 남아도 화면과 계산에서 무시한다. 문서 제목 변경은 기록을 유지하지만 문서 경로·데모 URL 변경은 새 항목으로 취급한다.
- `/study-progress`는 문서 콘텐츠가 아닌 개인 상태 화면이므로 문서 사이드바 트리 밖에 둔다. 플로팅 버튼과 Drawer가 공식 진입점이다.
- 브라우저 저장소를 사용할 수 없는 환경에서는 화면을 사용할 수 있지만 기록 보존을 보장하지 않는다.
