# Project: nextjs-ko-study-lab Demo Remediation

## Architecture
Multi-zones Next.js 16.3.1 monorepo with Turborepo and pnpm workspaces:
- `apps/shell` (Port 3000): Gateway, SSG Viewer, iframe embedding of demo routes (`/zone/:zone/:path*`).
- `apps/demo-baseline` (Port 3001): Standard App Router demo zone (`/zone/baseline/...`).
- `apps/demo-cache-components` (Port 3002): Next.js 16 Cache Components zone (`/zone/cache/...`).
- `packages/demos`: SSOT YAML metadata (`demos.yaml`), Zod schema validator (`lint.mjs`), compiled JSON manifest (`demos-manifest.json`).
- `packages/demo-kit`: Shared UI components (`DemoContainer`, `DemoGuideCard`, `ExpectedActualPanel`, `DemoResetButton`, `DemoDeepDiveCard`, `VerificationFooter`).
- `packages/test-suite`: Multi-tier E2E testing framework (`@study/test-suite`).

## Code Layout
- `apps/demo-baseline/src/app/zone/baseline/[category]/[demo-name]/`: Baseline demo entry points, components, and authentic file convention routes (`page.tsx`, `layout.tsx`, `route.ts`, `loading.tsx`, `error.tsx`, `template.tsx`, `not-found.tsx`, `@slot/`, `[id]/`, `[...slug]/`, etc.).
- `apps/demo-cache-components/src/app/zone/cache/[category]/[demo-name]/`: Cache components demo entry points and routes.
- `apps/demo-baseline/src/proxy.ts`, `apps/demo-baseline/src/instrumentation.ts`: Root-level proxy and instrumentation hooks.
- `packages/demos/demos.yaml`: Metadata source of truth with canonical doc wiring and demo definitions.
- `packages/demos/demos-manifest.json`: Compiled manifest generated by `pnpm --filter @study/demos build`.

## Interface Contracts
### `VerificationFooter.tsx` ↔ Demo Component
- Prop contract: `VerificationFooter` accepts dynamic inspection props (`isMatched?: boolean`, `expected?: string`, `actual?: string`, `status?: string`, `currentValue?: any`, `logs?: string[]`, `isLoaded?: boolean`, etc.) and evaluates 3-state regression detection.
- Lifecycle: `undefined` -> "검증 대기", `true` -> "검증 완료 (일치)", `false` -> "불일치 (Regression Detected)".

### Route Conventions ↔ Shell DemoIframe
- Path format: `/zone/${demo.zone}/${demo.url}`
- Sub-routes: Sub-routes (e.g. dynamic segment `/zone/baseline/file-conventions/dynamic-segments/single-param/items/PROD-101` or parallel routes) nest seamlessly under each demo's scoped directory without breaking shell iframe embedding.
