## 학습 목표

- 기본 프로젝트와 App Router의 핵심 흐름을 단계적으로 이해합니다.
- 각 주제를 실제 애플리케이션 상황과 연결합니다.
- 구현 가능한 주제는 시각적 데모와 검증 시나리오로 확장합니다.

- 설명: 개념, 사용 시점, 주의점을 정리합니다.
