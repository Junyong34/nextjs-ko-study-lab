# Next.js 학습 사이트 문서 컨텍스트

이 컨텍스트는 Next.js 공식 문서를 학습 콘텐츠와 시각적 데모로 확장하기 위한 용어를 정의합니다. 구현 세부사항보다 학습 문서가 다루는 개념과 경계를 기록합니다.

## Language

**학습 문서**:
공식 문서의 특정 메뉴를 학습 목표, 핵심 개념, 예제 설계, 확인 방법으로 재구성한 문서입니다.
_Avoid_: 단순 번역문, 구현 코드

**메뉴 페이지**:
공식 사이드바에서 하나의 링크로 식별되는 학습 단위입니다.
_Avoid_: 카테고리와 페이지를 혼용하기

**학습 카테고리**:
여러 메뉴 페이지를 공통 주제와 순서로 묶은 상위 문서입니다.
_Avoid_: 무관한 메뉴의 임의 묶음

**데모**:
학습자가 개념의 결과를 화면이나 상호작용으로 직접 확인하는 검증 장치입니다.
_Avoid_: 실행 방법만 설명하는 예제

**공식 출처**:
해당 학습 문서가 근거로 삼는 Next.js 공식 문서 링크입니다.
_Avoid_: 출처 없는 요약

**학습 경로**:
학습자가 메뉴를 어떤 순서로 탐색할지 정의한 흐름입니다.
_Avoid_: 사이드바의 단순 나열

**설계 단계**:
학습 목표와 문서 구조를 먼저 합의하고, 이후 예제와 코드를 구현하는 작업 단계입니다.
_Avoid_: 설명과 구현을 동시에 시작하기
