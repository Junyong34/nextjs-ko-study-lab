## Requirements

- 제목·짧은 안내·검색·줄바꿈 가능한 그룹 필터·결과 수·그룹별 행 목록 순서로 구성한다.
- 제목 영역 아래 얇은 경계와 24px 여백을 둔다. 그룹 제목은 18px 굵게 표시하며 개수는 중성 배지로 구분한다(2026-10-02 후속 사용자 승인).
- 17개 행은 하나의 상세 링크로 구성하며 기술명·짧은 요약·기술 배지·화살표를 표시한다.
- 제목·요약·설명·배지·keywords의 대소문자 무시, 공백으로 나눈 모든 검색어 포함 검색을 제공한다.
- q 검색은 history replace, 기존 group 필터는 push로 동기화한다. IME 조합 중 URL 변경을 미룬다.
- study_visualize_list_context에 목록 URL·선택·스크롤을 저장하고 1시간 안의 복귀 시 위치·포커스를 복원한다. 저장소 실패·만료·직접 진입은 기본 목록으로 돌아간다.
- 유효한 ?demo=는 상세로 연결하고 잘못된 demo는 무시한다. 잘못된 group은 전체로 처리한다.
- 상세의 반복 안내·상태 점·외곽 패널을 제거하고 관련 항목을 행 링크로 표시한다.
- 검색·목록·키보드에는 이동 효과를 넣지 않는다. 최소 44px 조작 영역과 focus-visible, 결과 수 알림을 제공한다.

## Non-goals

시각화 내부 재설계, 신규 콘텐츠·서버 API·공통 DemoMeta 변경, 전역 헤더·학습 기록 버튼, push·배포. 로컬 커밋은 후속 사용자 승인에 따른다.

셸에 목록 상태·검색·행·복귀 처리를 분리한다. 기존 기술명·긴 설명·버전 조건·내부 시각화는 유지한다. 필터는 전체 / 타임라인 비교 / 구조와 흐름 / Cache Components로 표시한다.
